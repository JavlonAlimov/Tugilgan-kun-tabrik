Sabrina uchun tug'ilgan kun tabrigi

Sayt namunadagi dizayn va animatsiyalar bilan tayyorlandi.
Ism: Sabrina. Yosh: namunadagi kabi 23.
Texnologiyalar: HTML, CSS, JavaScript. Build yoki server kerak emas.

Netlify orqali nashr qilish:
1. Netlify hisobingizga kiring: https://app.netlify.com/
2. https://app.netlify.com/drop sahifasini oching.
3. sabrina-tabrik papkasini yoki sabrina-tabrik.zip faylini yuklang.
4. Netlify bergan sayt havolasini oching va ulashing.

Git orqali ulaganda netlify.toml nashr papkasini belgilaydi.
Build command maydonini bo'sh qoldiring.

Sayt Netlify serverida ishlaydi; kompyuteringiz yoqilgan turishi shart emas.
Havola ishlashi sayt va hisobning faol bo'lishiga hamda xizmat shartlariga bog'liq.

Mahalliy ko'rish: sabrina-tabrik/index.html faylini brauzerda oching.
Google Fonts mavjud bo'lmasa, brauzer tizim shriftidan foydalanadi.

Qo'llanma: https://docs.netlify.com/start/quickstarts/netlify-drop-quickstart/

Musiqa: loyiha uchun yaratilgan original, vokalsiz instrumental kuy (assets/birthday-music.wav). Ochib ko'r bosilganda boshlanadi, pastdagi tugma orqali yoqiladi/o'chiriladi.
